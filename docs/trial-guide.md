# CareMate AI 試用指南 v0.1

> 目的：驗證兩件事——**① 外籍看護看得懂印尼文介面嗎？② 家屬會用「用說的」交代照護嗎？**
> 網址：**https://caremate.trucop.com**（手機瀏覽器直接開，不用安裝）

## 怎麼開始（給家屬）
1. 手機開 https://caremate.trucop.com
2. 底部 **🏠 Keluarga／家屬** → 家屬首頁（今日進度、血壓、待完成）
3. 底部 **➕ Tambah／新增** → 「用說的」建立任務 → 按 **AI 整理** 看解析結果
4. 底部 **📋 Ringkasan／摘要** → AI 每日摘要

## 怎麼開始（給看護）
1. 底部 **🧑‍⚕️ Perawat／看護** → 印尼文介面
2. 右上可切換語言：**ID ／ VI ／ 中文**
3. 每張任務卡右側：按 **Selesai**（完成）或 **Batalkan**（取消）
4. 有數值的任務（血壓）可輸入數字後記錄

## 給看護的 3 個問題（印尼文，請照著問）
1. **Apakah tulisan di layar ini mudah dibaca?**（畫面上的字看得懂嗎？）
2. **Setelah selesai, tombol mana yang Anda tekan?**（做完之後，你會按哪一個？）
3. **Bagian mana yang masih membingungkan?**（哪裡還看不懂／不清楚？）

## 給家屬的 3 個問題（中文）
1. 你會想用「**用說的**」交代照護，還是打字？
2. 「**待確認**」的提醒對你有幫助嗎？（例如「那個藥」沒說藥名時）
3. 每天最想收到哪一種摘要？

## 觀察重點（不要教她，看她自己做）
- 她能不能自己找到「今天要做什麼」
- 第一個按錯的地方在哪
- 她有沒有問你「這是什麼意思」
- 她完成一項之後，知不知道要按什麼

## 已知限制（先跟對方說，避免誤解）
- 這是**原型**：資料是示範資料，重新整理會回到初始狀態
- 語音輸入開發中（目前用打字；手機瀏覽器可先按住鍵盤的麥克風用系統聽寫）
- 目前沒有帳號與多人協作，是單機示範
